# Godot Platformer Starter — заготовка 2D-платформера

Учебная заготовка Школы GameDev (Creata Academy, SCH-3) для модулей G0 («курьер по крышам»), G2 (первый прототип) и капстоуна. Godot сам платформер не даёт, а официальный первый 2D-урок — не платформер, поэтому заготовка своя.

Курьер бегает по трём платформам, прыгает, и должен донести жёлтую посылку. Упал за край — уровень начался заново. Дошёл — «Уровень пройден!», R — ещё раз. Только встроенные средства Godot: графика — цветные `ColorRect`, ни аддонов, ни картинок.

**Версия:** Godot **4.7.2 stable** (проверено; `config/features` = 4.7). Рендерер Compatibility — он нужен для веб-экспорта. Лицензия — MIT (`LICENSE`, Creata Academy).

## Как открыть

1. Скачай Godot 4.7 (или новее 4.x) с godotengine.org.
2. В менеджере проектов: **Import** → выбери файл `project.godot` в этой папке → **Import & Edit**.
3. **F5** — запуск. Управление: стрелки или A/D — бег, пробел/W/стрелка вверх — прыжок, R — рестарт (настроено в Project Settings → Input Map).

## Структура

| Файл | Что делает |
|---|---|
| `scripts/player.gd` | Игрок: бег, прыжок, гравитация, койот-тайм, буфер прыжка. **Все ручки здесь.** |
| `scripts/game.gd` | Правила уровня: падение за край, финиш, рестарт по R |
| `scenes/player.tscn` | Игрок (CharacterBody2D + прямоугольник) |
| `scenes/main.tscn` | Уровень: платформы (StaticBody2D), посылка (Area2D), текст «Уровень пройден» |
| `tests/platformer_test.gd` | Автотест без окна |

## Где ручки

Открой `scenes/main.tscn`, выбери узел **Player** — справа в Инспекторе появятся числа из `scripts/player.gd`:

- `speed` — скорость бега;
- `jump_velocity` — сила прыжка (отрицательная: в Godot ось Y смотрит вниз);
- `gravity` — гравитация;
- `max_fall_speed` — предел скорости падения;
- `coyote_time` — «койот-тайм»: сколько секунд после схода с края ещё можно прыгнуть (0 — выкл.);
- `jump_buffer_time` — буфер: игра помнит нажатие пробела, сделанное чуть до приземления (0 — выкл.).

Линия падения — `fall_limit_y` у узла **Main** (`scripts/game.gd`).

## Три упражнения

**1. Поменяй силу прыжка.** Выбери Player, поставь `jump_velocity` = `-400`, запусти (F5): на вторую платформу уже не забраться. Потом `-800`: прыгаешь выше крыш. Найди значение, при котором уровень проходится, но не слишком легко. Попробуй менять `gravity` вместе с прыжком: прыжок получается «лунным» или «тяжёлым».

**2. Добавь вторую платформу.** В `main.tscn` выбери узел **Platform2** → Ctrl+D (дублировать). Подвинь копию инструментом перемещения. Платформа состоит из `StaticBody2D` + `CollisionShape2D` (твёрдость) + `Look` (картинка). Сделай лестницу так, чтобы до посылки было дольше идти. Подсказка: высота прыжка при стандартных числах около 110 пикселей, а перепад между платформами должен быть меньше.

**3. Исчезающая платформа.** Сделай платформу, которая пропадает через 1,5 секунды после того, как на неё встали. Важный урок: **прозрачность не отключает столкновения.** Если поставить платформе `modulate.a = 0`, она станет невидимой, но игрок всё равно будет стоять на ней в воздухе. Чтобы платформа правда исчезла, надо выключить её `CollisionShape2D`:

```gdscript
# скрипт на StaticBody2D платформы (добавь Area2D сверху, чтобы узнать, что на неё встали)
$Look.visible = false                       # картинку спрятали...
$CollisionShape2D.set_deferred("disabled", true)  # ...и твёрдость выключили
```

`set_deferred` нужен, потому что менять физику посреди расчёта столкновений нельзя — Godot сделает это в безопасный момент. Проверь: после исчезновения игрок должен падать, а потом платформа возвращается (таймер + то же самое с `false`).

Запуск без окна (при первом разе в чистой папке сначала `godot --headless --path . --import`):

```bash

```

## Экспорт в веб и выкладка на itch.io

Ссылки открыты и проверены 17.10.2026.

1. **Шаблоны экспорта.** Нужны export templates той же версии, что и редактор. В Godot: **Editor → Manage Export Templates… → Download and Install** (или установить из `.tpz` со страницы загрузки). Без них экспорт заблокирован. [Документация: экспорт проектов](https://docs.godotengine.org/en/stable/tutorials/export/exporting_projects.html)
2. **Пресет.** **Project → Export… → Add… → Web**. Файл назови `index.html`. **Thread Support оставь выключенным** — одно-поточный экспорт совместим с itch.io. Рендерер должен быть Compatibility (в этом проекте так и есть). [Документация: экспорт для веба](https://docs.godotengine.org/en/stable/tutorials/export/exporting_for_web.html)
3. **Собери.** **Export Project** в пустую папку `build/web/`. Получатся `index.html`, `.js`, `.wasm`, `.pck`, `.png`. Из консоли: `godot --headless --path . --export-release Web build/web/index.html`.
4. **Проверь локально.** Открытие `index.html` двойным кликом не работает — нужен веб-сервер. Скопируй `serve.py` из репозитория Godot в папку экспорта и запусти `python serve.py --root .`, либо используй кнопку запуска в вебе прямо из редактора.
5. **Упакуй.** Заархивируй **содержимое** папки в ZIP так, чтобы `index.html` лежал в корне архива (не в подпапке). Лимиты itch.io: до 1000 файлов, до 500 МБ в сумме, имена файлов чувствительны к регистру. [itch.io: HTML5-игры](https://itch.io/docs/creators/html5)
6. **Загрузи.** На itch.io создай проект (`/game/new`), **Kind of project → HTML**, загрузи ZIP и отметь **This file will be played in the browser**, задай размер окна встраивания (например 1152×648), сохрани и открой страницу для проверки. Страницу сначала держи в режиме Draft/Restricted, пока не проверишь.
